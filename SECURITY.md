# Security Policy / 安全策略

## Supported Versions / 支持的版本

Only the latest stable release builds are supported with security patches.

## Reporting a Vulnerability / 漏洞汇报

If you identify a security vulnerability (such as a buffer overflow, memory crash during high-concurrency pings, socket leak exploit, or remote file disclosure vulnerability), please do **not** open a public issue.

Please report vulnerabilities privately by emailing the maintainers or using GitHub's private vulnerability reporting feature.

如果您在测速引擎或网络扫描套接字中发现安全漏洞（如高并发 Ping 下的缓冲区溢出、内存崩坏、套接字泄漏等），请勿通过公开 Issue 报告，请使用 GitHub 的私有漏洞报告功能或直接发送电子邮件联系维护者。
